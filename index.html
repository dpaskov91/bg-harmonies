Scoring quick reference

Base game scoring. Always double-check tricky spots against the official rules.

🌳 Trees

1 / 2 / 3 stacked high → 1 / 3 / 7 pts each

⛰️ Mountains

1 / 2 / 3 stacked high → 1 / 3 / 7 pts each — only if next to another mountain group, else 0

🌾 Fields

Each separate group of 2+ → flat 5 pts, however big

💧 River

Length 2/3/4/5/6 → 2/5/8/11/15 pts, +4 per token beyond 6. Only your longest river counts.

🏠 Buildings

Flat 5 pts each, if surrounded by 3+ differently colored tokens

🦔 Animals & Spirits

Sum the printed value shown on each collected Animal card and Nature's Spirit card
